# Session Start Workflow

## For the Human
1. Open a new AI chat.
2. Run `./scripts/session_start.sh` in your terminal.
3. Copy the output (the `SESSION_CONTEXT.md` file).
4. Paste it as the very first message to the AI.

## For the AI
1. Read the `AGENTS.md` file.
2. Output the mandatory confirmation: `CONSTITUTION v1.0.0 LOADED. READY.`
3. Wait for the Human's next instruction.
