# 🏛️ The Global AI Constitution

**Version:** 1.0.0
**Status:** Active

This repository contains the immutable, project-neutral rules that govern all AI interactions, coding sessions, and agent behaviors across all projects (AIN, CareerOS, Aureon, CyberOS, etc.).

## Purpose
AI memory resets. Context windows fill up. To prevent AI drift and hallucination, this repository serves as the ultimate source of truth. The AI is bound by these rules. 

## Structure
- `constitution/`: The individual rules (One file per rule, numbered sequentially).
- `workflows/`: Standard operating procedures (Session Start/End).
- `scripts/`: Enforcement tools (Human-run only).
